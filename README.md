# ENGR 1340 Assignment 4 - Repo 1

**Student:** Brayden Lassiter

This public repository demonstrates the fork-based GitHub collaboration workflow for ENGR 1340 Assignment 4. It includes addition documentation, a teammate contribution submitted from a fork, and issue resolution with a closing commit reference.

## Files

- `addition.md` explains addition and provides accurate examples.
- `multiplication.md` will be added by a teammate through a fork-based pull request.

## Required teammate workflow

1. Fork this repository to your own GitHub account.
2. In your fork, create `multiplication.md` with a clear explanation and at least two correct examples.
3. Commit and push the change to your fork.
4. Open a pull request from your fork into this repository's `main` branch.
5. Separately, open an issue in this repository requesting one small, legitimate improvement to `addition.md`.
